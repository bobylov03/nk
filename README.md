# NC meals — готовый проект

Сайт, оформление рациона по анкете, личный кабинет клиента и админ-панель.
Без сборки и без внешних библиотек — нужен только Node.js 18+.

## Запуск

```bash
cd nc-meals
node server.js
```

Откроется на http://localhost:3000

| Страница | Адрес | Назначение |
|---|---|---|
| Главная | `/` | меню дня, тарифы, доставка — тексты берутся из админки |
| Оформление | `/order.html` | анкета → заявка → подтверждение → оплата |
| Кабинет клиента | `/cabinet.html` | вход по телефону, меню, КБЖУ, пауза, замены |
| Админ-панель | `/admin.html` | пароль `nc2026` |

Демо-клиент для входа в кабинет: **+995 555 12 34 56** (Нино Церетели).

## Логика заказа

1. Клиент заполняет анкету (тариф, число приёмов, исключения, адрес, окно доставки).
2. Заявка попадает в админку со статусом «На согласовании». Оплата закрыта.
3. Вы нажимаете «Подтвердить» на дашборде или в разделе «Заказы».
4. У клиента открывается шаг оплаты (страница обновляет статус сама, либо по ссылке `/order.html?order=ID`).
5. После оплаты создаётся клиент с рационом, дни зачисляются, заказ уходит в историю.

Замены блюд и пауза тоже проходят через подтверждение: клиент отправляет запрос, вы подтверждаете — только после этого меню меняется.

## Добавление блюд (два способа)

**Умная строка** — одна строка превращается в блюдо:

```
Средиземноморский боул / завтрак / 420 ккал / 24-18-32 / 350 г / 18 / веган, без глютена
```

Порядок частей произвольный, распознаются: категория, «ккал», Б-Ж-У, вес с «г», число = цена, остальное — теги.
Кнопка «Дублировать похожее» подставляет все параметры существующего блюда.

**Таблица / Excel** — вставьте диапазон, колонки через `;`, `,` или табуляцию:

```
название; категория; ккал; Б; Ж; У; вес; цена; теги; состав
```

Фото: положите файл в `public/img/` и укажите его имя в поле «Файл фото» (например `food-boul.jpg`).

## Меню недели

Раздел «Меню дня»: перетащите блюдо из библиотеки в слот дня (клик по заполненному слоту очищает его).
«Заполнить автоматически» закрывает пустые слоты на 7 дней вперёд.

## Структура

```
nc-meals/
  server.js          сервер + REST API (без зависимостей)
  data/db.json       вся база: блюда, меню, тарифы, клиенты, заявки, тексты
  public/
    index.html       главная
    order.html       анкета и оплата
    cabinet.html     личный кабинет
    admin.html       админ-панель
    css/nc.css       стили и фирменные токены (--plum, --champagne, --bg, --tile-r)
    js/nc.js         помощники: запросы, тосты, плитки
    js/dish-sheet.js карточка блюда (модальное окно)
    img/             фотографии блюд
```

### Форма фотографий

Квадрат со скруглением 22px (как в инстаграме) — по умолчанию. Круглые фото: в `public/css/nc.css` поставьте
`--tile-r:50%` и `.hero-photo{border-radius:50%}`. Больше нигде править не нужно.

### Карточка блюда

Клик по блюду на главной или в кабинете открывает карточку: фото, описание, КБЖУ, вес, состав,
аллергены (определяются по составу автоматически) и блок «Почему это блюдо сегодня».
Описание и «почему» заполняются в админке — в форме добавления блюда и прямо в таблице «Блюда».

### Блок «Обо мне»

Тексты — в админке, раздел «Контент сайта» (поля «Обо мне …»). Фото: положите квадратный файл в
`public/img/` и укажите имя в поле «Обо мне — файл фото». Пока имя пустое, на месте фото стоит слот-заглушка.

Фирменный цвет один — `--plum: #4a243d`, фон — светлый шампань `--bg: #f6ebdd`, акцент `--champagne: #dcc0a6`,
декоративные линии — тонкое золото `--gold`. Меняете переменные в `public/css/nc.css` — меняется весь проект.

## API (кратко)

Публичное: `GET /api/public`, `GET /api/dishes`, `POST /api/orders`, `GET /api/orders/:id`, `POST /api/orders/:id/pay`
Клиент: `POST /api/client/login`, `GET /api/client/:id`, `POST /api/client/:id/{pause,swap,extend}`
Админ (заголовок `X-NC-Token` после `POST /api/admin/login`):
`GET /api/admin/state`, `POST|PUT|DELETE /api/dishes...`, `POST /api/dishes/bulk`, `PUT /api/menu`,
`POST /api/menu/autofill`, `PUT /api/tariffs/:id`, `PUT /api/content`, `PUT /api/clients/:id`,
`POST /api/orders/:id/{approve,reject}`, `POST /api/requests/:id/{approve,reject}`

## Что заменить перед запуском в бой

- Пароль админки в `data/db.json` → `admin.password`.
- Фото блюд в `public/img/` на оригиналы (сейчас кадры из инстаграма) и добавьте квадратное фото шефа.
- Платёжный шаг — сейчас имитация: `POST /api/orders/:id/pay` просто помечает заказ оплаченным.
  Подключите платёжный шлюз (BOG / TBC / Stripe) в этом обработчике.
- Данные лежат в JSON-файле. Для нескольких сотен клиентов этого хватает; дальше — перенос на PostgreSQL/SQLite.
